# Уведомления о заявках в Telegram

Каждая новая заявка с сайта сразу приходит сообщением в Telegram-чат: подключение, проблема или обратный звонок. В сообщении есть:
- тип заявки, имя и кликабельный телефон;
- тема, адрес и контекст (например, выбранный тариф);
- текст сообщения, язык и страница, с которой отправили заявку;
- ссылка «Відкрити в адмінці».

Нужны два значения:
- `TELEGRAM_BOT_TOKEN` — токен бота;
- `TELEGRAM_CHAT_ID` — чат, куда писать.

Если их не задать, заявки сохраняются только в Strapi, а в логе при старте будет предупреждение `lead notifications are disabled`.

> Токен бота — секрет: любой, у кого он есть, может писать от имени бота. Не коммитьте его, не пересылайте в чатах и не вставляйте в сторонние сервисы. Если токен утёк, отзовите его: @BotFather → `/revoke`.

---

## 1. Создать бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Укажите имя, например `NovaLine Заявки`, и username, который заканчивается на `bot`, например `novaline_leads_bot`.
3. BotFather пришлёт токен вида `1234567890:AAH…`. Это `TELEGRAM_BOT_TOKEN`.

Дополнительно можно поставить аватар (`/setuserpic`) и описание (`/setdescription`).

## 2. Создать чат для менеджеров

**Вариант А — группа (рекомендуется):** уведомления видит вся команда.

1. Создайте группу, например `NovaLine — заявки`, и добавьте в неё менеджеров.
2. Добавьте в группу бота: «Добавить участника» → найдите его по username.
3. Отправьте в группу сообщение `/start@novaline_leads_bot` (подставьте username своего бота). Это нужно, чтобы бот увидел группу.

**Вариант Б — личные сообщения:** уведомления получает один человек. Откройте бота и нажмите «Start».

## 3. Узнать chat id

Откройте в браузере эту ссылку, подставив свой токен (ссылка содержит токен, никому её не отправляйте):

```
https://api.telegram.org/bot<TOKEN>/getUpdates
```

В ответе найдите блок `"chat": { "id": … }`:
- у группы id отрицательный, обычно `-100…`, например `-1001234567890`. Копируйте вместе с минусом;
- у личного чата id положительный.

Если ответ пустой (`"result": []`), отправьте в чат ещё одно сообщение (`/start@<бот>` в группе или любое в личке) и обновите страницу.

Второй способ — терминал:

```bash
curl -s "https://api.telegram.org/bot<TOKEN>/getUpdates" | grep -o '"chat":{"id":-\?[0-9]*'
```

## 4. Проверить, что бот может писать в чат

```bash
curl -s "https://api.telegram.org/bot<TOKEN>/sendMessage" \
  -d chat_id=<CHAT_ID> -d text="Тест уведомлений NovaLine"
```

Ответ `"ok":true` и сообщение в чате означают, что всё настроено. Ошибки разобраны в разделе 7.

## 5. Прописать значения в Strapi

Откройте `novaline-be/.env` на сервере или локально и заполните:

```dotenv
TELEGRAM_BOT_TOKEN=1234567890:AAH...
TELEGRAM_CHAT_ID=-1001234567890
```

Docker читает `.env` только при создании контейнера, поэтому контейнер Strapi нужно пересоздать:

```bash
# сервер (novaline-be/deploy)
docker compose -f docker-compose.prod.yml --env-file .env up -d --force-recreate cms

# локально (папка therecom/)
docker compose -f docker-compose.dev.yml up -d --force-recreate cms
```

Сайт при этом продолжает работать, но заявки, отправленные в течение ~30 секунд перезапуска Strapi, получат ошибку.

## 6. Проверка на сайте

1. В логе Strapi больше нет предупреждения `lead notifications are disabled`:
   ```bash
   docker compose -f docker-compose.prod.yml --env-file .env logs cms | grep -i telegram
   ```
2. Отправьте на сайте заявку на обратный звонок (кнопка «Зворотній дзвінок»). Через 1–2 секунды в чате появится сообщение «📞 Зворотний дзвінок» с номером и ссылкой на заявку в админке.
3. Удалите тестовую заявку в Strapi: Content Manager → Lead.

## 7. Если сообщения не приходят

| Симптом (ответ curl из шага 4 или лог Strapi) | Причина | Что сделать |
|---|---|---|
| `401 Unauthorized` | Неверный или отозванный токен | Проверить токен, при необходимости `/token` в @BotFather |
| `400 Bad Request: chat not found` | Неверный chat id, потерян минус или `-100` | Повторить шаг 3 |
| `403 Forbidden: bot was kicked` / `bot is not a member` | Бота удалили из группы | Добавить бота обратно |
| `400 … group chat was upgraded to a supergroup` | Группа стала супергруппой, id сменился | Взять новый id из `migrate_to_chat_id` в ответе и обновить `.env` |
| В логе Strapi `[lead] Telegram notification failed …` | Сервер не достучался до api.telegram.org | Проверить исходящий доступ с VPS: `curl -sI https://api.telegram.org` |
| Ничего нет, в логе предупреждение при старте | Переменные не подхватились | Проверить `.env` и пересоздать контейнер (шаг 5) |

Если уведомление не отправилось, заявка всё равно сохраняется в Strapi и не теряется. Регулярно просматривайте Content Manager → Lead (фильтр по статусу `new`).

## Несколько получателей

Бот пишет в один чат. Если уведомления нужны нескольким людям, используйте группу (вариант А): добавлять и убирать менеджеров можно без изменений на сервере.
